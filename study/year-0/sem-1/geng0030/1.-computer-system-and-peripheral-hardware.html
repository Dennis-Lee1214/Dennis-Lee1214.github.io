1. Computer system and peripheral Hardware

计算机发展历程

第一代 1940-1956 真空管 Vacuum Tubes

  • ENICA（18000根真空管，27吨，1800平方英尺）
  • 极大、极耗电，输入用打孔纸带和磁带
  • 编程语言：机器语言machine code

第二代 1957-1963 晶体管 Transistors

  • 比真空管更小、更快、更少热量
  • 引入CPU，内存，I/O单元
  • 编程语言：FORTRAN(1956), ALGOL(1958), COBOL(1959)

第三代 1964-1971 集成电路 Integrated Circuits(IC)

  • 一片硅芯片包含多个晶体管/寄存器/电容
  • 更快更可靠，内存更大
  • 高级语言BASIC，小型机minicomputer出现，例如IBM 360，IBM370

第四代 1971-至今 微处理器 Microprocessor

  • 一个芯片完成所有运算、逻辑、控制功能
  • 体积小，可携带，个人电脑和计算机网络诞生
  • 存储：RAM、ROM
  • 例如IBM PC，Apple mac

第五代 未来 人工智能 Artificial Intelligence(AI)

  • 理解自然语言，语音识别，模拟人类行为
  • 速度最快，尺寸最小
  • I/o: 触屏、触摸板、语音、扫描、打印机等
  • 例如桌面、笔记本、平板、智能手机

计算机类型分类

微型计算机 Micro Computers

  • 单CPU，单用户。家庭/办公/学校使用
类型 说明
Personal Computer(PC) 个人使用的微型计算机
Laptop 小型、可携带的PC
Workstation 供商业专业人士使用的高性能网络PC
Network Server 协调网络通信和资源共享的更强大微型计算机

小型计算机 Mini Computers

  • 比主机便宜/功能少，但比PC/贵功能强
  • 又称mid-servers
  • 用于科学/工程计算、商业事务处理、文件处理、数据库管理

大型主机 Mainframe Computers

  • 大型机构使用，处理大批量关键任务
  • 例如人口普查，行业规划，大规模事务处理

超级计算机 Supercomputers

  • 专门解决复杂科学和工业问题
  • 例如气候研究，天气预报，基因组测序
  • 提供极大的计算能力

硬件功能

功能 说明 例子
Input 输入 接受输入数据，转换为电子形式 键盘，鼠标，光学扫描仪
Processing 处理 处理接收到的数据 CPU（含ALU算数逻辑单元+Control Unit控制单元）
Output 输出 将处理结果以人类可读的形式呈现 显示器、打印机
Primary Storage 主存 直接供CPU使用的内存 RAM，ROM
Secondary Storage 辅存 长期保存数据 磁盘、光盘

控制Control：CPU中的控制单元（Control Unit）负责控制计算机其他所有组件

处理速度

时间单位
Millisecond 毫秒 千分之一秒
Microsecond 微秒 百万分之一秒
Nanosecond 纳秒 十亿分之一秒
Picosecond 皮秒 百亿分之一秒
速度单位
MIPS 百万条指令/秒
Teraflops 万亿浮点运算/秒（超级计算机）
MHz 兆赫 百万次循环/秒
GHz 吉赫 十亿次循环/秒

外部设备

什么是外部设备

  • 所有输入，输出和辅助存储设备的统称。是计算系统的一部分，但不是CPU本身
  • 联机设备(Online)：与CPU分离但电子连接并受其控制（外部设备Peripherals属于此类）
  • 脱机设备(Offline)：与CPU分离且不受其控制

输入技术

键盘与GUI

  • 键盘是最广泛使用的输入设备。图形用户界面（GUI）通过图标、菜单、按钮进行选择操作、

指向设备 Pointing Devices

设备 说明
Mouse 电子鼠标
Trackball 固定不动，滚球移动光标
Pointing Stick 键盘上的橡皮头，通过压力移动光标
Touchpad 手指在矩形感应面上移动光标
Touch Screen 红外线/声波/电流网络，触碰即断开

笔试输入 Pen-based Computing

  • 用于平板电脑和PDA。压感层在液晶屏下方，配合软件数字化手写/绘图

语音识别 Speech Recognition

类别
Discrete 那个单词之间需停顿
Continuous 按正常语速说话
  • 系统将语音与音频模式库比对。需要Training训练识别个人声音或Speaker Independent（无需训练）

光学扫描 Optical Scanning

  • 读取文字或图形并转为数字输入
类型
Flatbed scanner 平板扫描仪 扫描文档和图像
OCR 光学字符识别 读取字符和条码，用于商品标签、邮件分拣、试卷评分
Wand 扫描棒 读取条形码如UPC
其他输入技术
Magnetic stripe 磁条 读取信用卡磁条
Smart card 智能卡 内置微处理器芯片和内存信用卡
Digital Camera数码相机 数字图像输入
MICR 磁墨字符识别 银行支票底部磁性墨水印刷的账号

输出技术

视频显示Video Displays
CRT 阴极射线管 类似电视，多数台式电脑屏幕
LCD 液晶显示 笔记本/PAD/部分 PC
打印输出 Printed Output
Inkjet 喷墨打印机 墨水喷射到纸上
Laser 激光打印机 静电感光过程，类似复印机

存储技术

二进制表示 Binary Representation

  • 计算机通过信号的有无（ON=1，OFF=2）处理和存储数据

Bit与Byte

Bit（位） = 最小数据单元，0或1
Byte（字节）= 8个bit，代表一个字符或数字

存储容量单位
Byte 8 bits
KB 约一千bytes
MB 约一百万bytes
GB 约十亿Bytes
TB 约万亿bytes
PB 约千万亿bytes

直接访问 VS 顺序访问

  • Direct Access（直接/随机）：每个位置有唯一的地址，访问时间相同。例：半导体内存芯片、磁盘。
  • Sequential Access（顺序）：必须按顺序读取。例：磁带Magnetic tape

半导体内存 Semiconductor

  • RAM（随机存取）= 易失性volatile，断电丢失，可读写，最常用主存
  • ROM（只读）= 永久存储，只读不写，制造时烧录程序，称为固件firmware
