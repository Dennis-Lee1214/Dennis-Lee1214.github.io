Formal Proof

Proposition and Predicate 命题与谓词

  1. proposition 命题

    • 定义:Declarative statements with a definite truth value (true or false), rather than subjective opinions. 有确定真值(T or F)的陈述句，非主观意见
    • Example：Johor is in Malaysia.

  2. Predicate 谓词

    • 定义:Contains variables; the truth value depends on the values ​​assigned to the variables. 含变量，真值取决于变量取值
    • Example: P(x): x>8 if P=9,T

  3. Neither 两者皆非

    • Example: 疑问句、命令、主观、悖论; What's you name?, This statement is false.

Components of a formal proof 形式证明的组成

  1. Components 组成
    • Premises 前提：假设为真的陈述，证明起点。
    • Conclusion 结论：需建立的陈述。
    • Arguments 论证：从前提推导结论的逻辑步骤。
  2. 可借助Axioms公理和已证结果（定理和引理）
    • 可写为P→Q 形式
    • Axioms 公理: 无需证明即接受为真
    • Theorem 定理：已证明的命题
    • Lemma 引理：辅助证明其他结果的已证命题

Proof method 证明方法

  1. Direct proof 直接证明: 从前提直接推导结论
  2. Proof by cases 分情况证明: 划分所有可能情况逐一证明
  3. Proof by contrapositive逆否证明: 证明非Q→非P代替P→Q 
  4. Proof by contradiction反证法：假设命题为假，推出矛盾
  5. Mathematical induction数学归纳法：证基础情况，再证每步递推

Example

Proposition 命题:

  • The 1st of October is a Wednesday, so the 13th of October is a Monday

Premises 前提:

  • October is a Wednesday.
  • The days of the week repeat every seven days in their usual order.
  • 13 October is 12 days after 1 October.

Argument 论证:

  • Since 12 = 7 + 5, moving forward 7 days from Wednesday returns to Wednesday.
  • Moving forward another 5 days gives Monday.
  • Therefore, 13 October is a Monday.

Conclusion 结论:

  • 13 October is a Monday.

  • 证明 = 前提 + 论证 + 结论。

证明方法

  1. Direct proof 直接证明

    • 证 P→Q: 假设 P,用定义一步步推到 Q
    • 模版：假设P → 用定义展开 → 凑出Q的定义形式
      • 例: 若 18|n,则 6|n n可以被18整除，则n可以被6整除
        • 假设n = 18k，k∈ℤ
        • 18=6×3,所以 n=6(3k)
        • 3k 是整数
        • 所以 n=6m, m=3k∈ℤ, 即 6|n
      • 例：两个奇数之积是奇数
        • 设 a=2k+1, b=2m+1
        • ab=4km+2k+2m+1 =2(2km+k+m)+1
        • 2km+k+m 是整数,所以 ab 是奇数

  2. Counterexample 反例

    • 推翻全称命题:找一个 P 真、Q 假的例子
      • 例: a²=b² ⟹ a=b
        • 证明是假的,取 a=2,b=−2。应该改成 a=b 或 a=−b,或加条件 a,b≥0

  3. If and only if 当且仅当

    • 证 P↔Q:两个方向都要证
    • 先假设P，推出Q，再重新假设Q，推出P
      • 例：x²=x ⟺ x=0 或 x=1
        • ⇒x²−x=0,即 x(x−1)=0,所以 x=0 或 x=1
        • ⇐:x=0 时 0²=0,x=1 时 1²=1

  4. Contraposition 逆否命题

    • P→Q ≡ ¬Q→¬P (逻辑等价)
    • 用的时机：证"n² 偶 ⟹ n 偶"时,n²=2k 很难变成 n 的形式。逆否命题"n 奇 ⟹ n² 奇"则很顺:n=2k+1, n²=2(2k²+2k)+1
      • 例：x+y≥2 ⟹ x≥1 或 y≥1
        • 逆否: x<1 且 y<1 ⟹ x+y<2
        • 两个不等式相加:x+y<1+1=2

  5. Case analysis 分情况

    • 分的情况加起来必须覆盖所有情况；每个情况都要单独证明
      • 例：n²+3n 是偶数
        • n=2k: 4k²+6k=2 (2k²+3k)
        • n=2k+1:4k²+10k+4 =2 (2k²+5k+2)
        • 每个整数非奇即偶,所以情况穷尽

  6. Contradiction 反证法

    • 假设结论为假 → 推出矛盾 ⊥ → 原结论成立 不能只写矛盾，要写清楚和什么矛盾
    • contraposition逆否命题 和 contradiction反证法的区别：
    • contraposition：目标是 P→Q,假设 ¬Q, 必须推出 ¬P,目标明确
    • Contradiction：假设整个命题为假, 推出任何矛盾都行
      • 例：没有最小正实数
        • 假设 x 是最小正实数,取 y=x/2。
        • y>0 且 y<x, 与"x 最小"矛盾

  7. Induction 归纳法

    • 类似于多米诺骨牌
    • Base case：证明 P(1) 成立(推倒第一块)
    • Inductive hypothesis：假设某个 k 使 P(k) 成立
    • Inductive step：证明 P(k+1)(每块推倒下一块)
      • 例：2ⁿ≥n+1
        • Base:n=1, 2¹=2≥2
        • Step:假设 2ᵏ≥k+1。则 2ᵏ⁺¹=2·2ᵏ ；2·2ᵏ ≥ 2(k+1) ；2(k+1) = 2k+2；2k+2 ≥ k+2
        • 2ᵏ⁺¹ = 2·2ᵏ ≥ 2(k+1) = 2k+2 ≥ k+2
        • 所以 2ᵏ⁺¹ ≥ k+2,这正是 P(k+1)
        • 用到的两个不等式:归纳假设 2ᵏ≥k+1,以及 2k+2≥k+2

Sets, Functions and Relations

Basic of sets 集合基础

  • 定义：互不相同，定义明确的对象的集合
  • 写法：
    • Roster:D={0,1,2,3}
    • Set-builder:I = {i∈ℤ : 0≤i<4}, 冒号读作"such that"
  • 集合不记顺序和重复，因此 {1,2,3}={3,2,1}={1,1,2,3}
  • | A | 的意思是集合中不同元素的个数
    • 例如 |{1,1,2,2,3}| = 3
  • ∅ 和{∅}的不同：∅没有元素，因此｜∅｜ = 0；{∅}里有一个空集元素，因此为1；空集是任何集合的子集
  • ⊆ 的意思代表A的每个元素都在B里面；⊊ 代表A是B的子集，但A不等于B

Sets operations 集合运算

逻辑 运算 意思
OR A∪B 在 A 或 B(包含两者都在)
AND A∩B 在 A 且在 B
AND NOT A∖B 在 A 不在 B(顺序有关)
NOT Aᶜ=U∖A 不在 A(要先知道全集 U)

  • Example：

    • U={1..6}, A={1,2,4,6}, B={2,3,4}
    • A∪B={1,2,3,4,6}
    • A∩B={2,4}
    • A∖B={1,6}
    • Aᶜ={3,5}

  • 常用定律：

    • 恒等: A∪∅=A, A∩U=A
    • 幂等: A∪A=A, A∩A=A
    • 互补: A∪Aᶜ=U, A∩Aᶜ=∅, (Aᶜ)ᶜ=A
    • 交换律与结合律: ∪ 和 ∩ 都满足,但 ∖ 不满足交换律
    • 分配律: A∩(B∪C)=(A∩B)∪(A∩C)
    • De Morgan: (A∪B)ᶜ=Aᶜ∩Bᶜ, (A∩B)ᶜ=Aᶜ∪Bᶜ 口诀：把 NOT 推进去, OR 和 AND 互换

  • 证明集合等式：

    • 取任意 x,用"每步等价"的方式推
      • Example:
        • x∈(A∪B)ᶜ ⟺ x∉A∪B ⟺ x∉A 且 x∉B ⟺ x∈Aᶜ∩Bᶜ

Ordered Pairs, Cartesian Products, and Power Sets 有序对，乘积与幂集

  1. Ordered pair有序对：(a,b) = (c,d) 当且仅当 a=c 且 b=d，例如 (2,5) ≠ (5,2),但 {2,5} = {5,2}

  2. Tuple 元组：固定位置数的记录，如 (student_id, module, mark)=(31415,”COMP1311",78)

  3. Cartesian product 笛卡尔积 A×B={(a,b) : a∈A, b∈B}

    • A={u₁,u₂}, B={read,write}:A×B 有 4 个对：A × B = {(u₁,read),(u₁,write),(u₂,read),(u₂,write)}
    • 独立选择相乘:3 个系统×2 个浏览器×2 种模式=12 个测试用例
    • A×∅=∅;只允许部分组合时,得到的是 A×B 的子集

  4. Power set 幂集：𝒫(A) 是 A 的所有子集的集合

    • 它的元素是子集,不是 A 的元素
    • 𝒫({a,b}) = {∅,{a},{b},{a,b}}
    • 每个元素"选或不选"两种,所以 |A|=n 时 |𝒫(A)| = 2ⁿ
    • 3个元素即为1+3+3+1 = 8个子集
    • Bit string位字符：顺序固定为 (logging, caching, encryption) 时,101 表示 {logging, encryption}
      • 位字符串提供了子集的紧凑表示
    • 𝒫(∅)={∅}, 大小为 2⁰=1, 幂集永远不为空

  5. Relation 关系:R⊆A×B,即"真正成立的那些对"

  6. Function 函数 f:A→B:对每个 a∈A,输出存在且唯一。两个输入可以共用一个输出,但一个输入不能有两个输出

    • A={1,2,3}, B={a,b}
    • P={(1,a), (2,b),(3,b)}:是函数
    • Q={(1,a), (1,b), (2,a), (3,b)}:不是函数, 1有两个输出(唯一性失败)
    • T={(1,a), (2,b)}:不是函数, 3没有输出 (存在性失败)

  • Example：U={u₁,u₂}, R={viewer,admin}, F={cache,logs}

    • 用户-角色可能对:2×2 = 4
    • 功能配置数:|𝒫(F)| = 2²=4
    • 实际允许的用户-角色对:一个 relation (U×R 的子集)
    • 每个用户恰有一个默认角色:一个 function U→R

Relation 关系

  1. 什么是relation
    • 关系 R 是笛卡尔积的子集:R ⊆ A × B,即 R = {(a, b) | a ∈ A 且 b ∈ B}
    • 通俗理解：Relation就是“把集合里的元素连起来的方式”，R里的每个有序对就是一条连线
    • Example：
      • A = {1,2,3}, R = {(1,2),(2,3)} → “1 与 2 相关, 2 与 3 相关”
      • 颜色与水果:C = {red, orange, yellow}, F = {apple, orange, lemon}
        • R = {(apple, red), (orange, orange), (lemon, yellow)}
        • F × C 共有 3 × 3 = 9 个有序对, 而 R 只有 3 个 → R 只是 F × C 的一个子集
    • Digraph 有向图:用箭头表示关系，每个有序对(a,b)画成一条从a指向b的箭头; (a,a)是自环
  2. Six Types of Relational Properties 6种关系性质
性质 形式化定义 理解 有向图特征
Reflexive 自反 ∀a∈A, (a,a)∈R 每个元素都和自己相关 每个点都有自环
Irreflexive 非自反 ∀a∈A, (a,a)∉R 没有元素和自己相关 每个都没有任何自环
Symmetric 对称 (a,b)∈R ⇒ (b,a)∈R 有去必有回 箭头都是双向的
Asymmetric 非对称 (a,b)∈R ⇒ (b,a)∉R 有去必无回 无双向箭头,也无自环
Transitive 传递 (a,b)∈R 且 (b,c)∈R ⇒ (a,c)∈R 能走两步到的,必须能一步直达 a→b→c 时必有 a→c
Antisymmetric 反对称 (a,b)∈R 且 (b,a)∈R ⇒ a=b 不同元素不能互相指向 双向箭头只允许是自环

  1. Equivalence Relations and Equivalence Classes 等价关系与等价类

    • 给元素分组
    • 等价关系：同时满足自反+对称+传递，记作“~”
    • 等价关系中将集合元素分类到buckets中，每个buckets被称为等价类
    • [a] = {x ∈ A : x ~ a}
    • 重要性质：
      • 每个元素恰好属一个类
      • 各类互不重叠
      • 所有类合起来覆盖整个集合
    • Example:
      • (首字母相同):A = {apple, ant, ball, bat, cat}
      • [apple] = {apple, ant}, [ball] = {ball, bat}, [cat] = {cat}

  2. Partial Order 篇序

    • 给元素排高低
    • 定义：同时满足Reflexive 自反，Antisymmetric 反对称，Transitive 传递
    • 通常写作 a ≼ b 代替 (a,b)∈R。此时 (A, R) 称为poset偏序集
    • 类似 ≤, 但不要求所有两个元素都能比较
    • 严格篇序：把自反换成非自反,即 非自反 + 反对称 + 传递 (符号< )

Function 函数

  • function是一种特殊的relation
  • 规则：定义域里的每个元素，都恰好对应培域里的一个元素，不能一对多
  • 记作：𝑓 :𝑋 →𝑌，并且 𝑓 ={(𝑥,𝑓(𝑥))} ⊆𝑋 ×𝑌
  • 术语：
    1. 定义域：
      • Domain，𝐷𝑜𝑚(𝑓) =𝑆，含义：所有输入
    2. 陪域：
      • Codomain，𝑇， 含义：所有"允许的"输出
    3. 值域/像:
      • Range / Image，𝑖𝑚𝑔(𝑓) ={𝑓(𝑥) ∣𝑥 ∈𝑆}, 实际被打中的输出
    4. Example：
      • 𝐴 ={𝑎,𝑏,𝑐}，𝐵 ={1,2,3,4,5}，𝑓 ={(𝑎,2),(𝑏,1),(𝑐,3)}
      • Domain = {𝑎,𝑏,𝑐}
      • Codomain = {1,2,3,4,5}
      • Range = {1,2,3}

Injective 单射

  • 不同的输入一定得到不同的输出，没有两个箭头指向同一个点
  • 陪域里的每一个元素，被至多1个(0或1个)输入指向
  • 形式定义: 𝑓(𝑥1)=𝑓(𝑥2)⟹𝑥1=𝑥2
  • 证明:
    • 思路：假设 𝑓(𝑎) =𝑓(𝑏)，推出 𝑎 =𝑏
    • 证明 𝑓(𝑥) =2𝑥 +1 是单射：2𝑎+1=2𝑏+1⇒2𝑎=2𝑏⇒𝑎=𝑏
    • 证明不是单射则找两个不同的输入得到相同的输出

Surjective 满射

  • 陪域里每一个元素都至少被一个箭头打中，没有空着的输出
  • 陪域里每个元素被至少 1 个输入指向
  • 形式定义: ∀𝑏∈𝐵, ∃𝑎∈𝐴 such that 𝑓(𝑎)=𝑏
  • 证明:
    • 思路：任取 𝑦 ∈𝑇，反解出 𝑥，并检查 𝑥 确实在定义域里
    • 证明 𝑓(𝑥) =2𝑥 +1（ℝ →ℝ）是满射：
      • 任取 𝑦 ∈ℝ，令 𝑦 =2𝑥 +1
      • 解得 𝑥 =𝑦−12
      • 这个 𝑥 仍然是实数 → 满射
    • 证明不是满射则找一个陪域里打不中的元素：
      • 𝑔(𝑥) =𝑥2：取 𝑦 = −1，没有实数 𝑥 满足 𝑥2 = −1 → 不是满射

Bijective 双射

  • 即是单射又是满射
  • 两边每个元素都恰好有一个输入指向

Inverse function 反函数

  • 定义：𝑓 是双射⟺𝑓 有反函数 𝑓−1
  • cancellation identities 消去恒等式:𝑓(𝑓−1(𝑦))=𝑦𝑓−1(𝑓(𝑥))=𝑥
    • 也就是𝑓 和 𝑓−1 复合起来等于什么都没做
  • 求反函数的三步:
    1. 确认 𝑓 是双射
    2. 交换 𝑥 和 𝑦：𝑦 =𝑓(𝑥) 变成 𝑥 =𝑓(𝑦)
    3. 解出 𝑦，得到 𝑦 =𝑓−1(𝑥)
    • Example:𝑓(𝑥) =2𝑥 +1
      1. 确认是双射
      2. 𝑥 =2𝑦 +1
      3. 𝑦 =12(𝑥 −1)，所以 𝑓−1(𝑥) =12(𝑥 −1)
      4. 验算：𝑓(𝑓−1(𝑥)) =2 ⋅12(𝑥 −1) +1 =𝑥

Cardinality 基数

  • 基数 = 集合里元素的个数，记作 |𝐴|
    • |{𝑎,𝑏,𝑐}| =3
    • |{{1,2},{3}}| =2
    • |{}| =0
  • 有限集的规则
    • 容斥原理 inclusion–exclusion： |𝐴 ∪𝐵| =|𝐴| +|𝐵| −|𝐴 ∩𝐵|
    • 不相交时: |𝐴 ∪𝐵| =|𝐴| +|𝐵|
    • 幂集： |𝑃(𝐴)| =2|𝐴|
    • Example:
      • 𝐴 ={1,2,3}，𝐵 ={3,4} → |𝐴 ∪𝐵| =3 +2 −1 =4，|𝑃(𝐴)| =8

Infinite sets 无穷集合

  • Countably Infinite 可数无穷

    • 如果一个集合能和 ℕ ={1,2,3,…} 建立双射，它就是可数无穷的，基数记作 ℵ0（读 aleph-null / aleph-zero）
    • ℵ0 是最小的无穷
    • Example:
      • 𝐴 ={1,2,3,…}，𝐵 ={2,4,6,…}，取 𝑓(𝑛) =2𝑛
      • 单射：2𝑛1 =2𝑛2 ⇒𝑛1 =𝑛2
      • 满射：任意偶数 2𝑘 都有原像 𝑘
      • 所以是双射，|𝐴| =|𝐵| =ℵ0
      • 因此偶数和自然数一样多, 基数看的是能不能配对, 不是谁包含谁

  • 无穷集合

    • 定义: 集合 A 是无穷的 ⟺ A 能和它自己的某个真子集（proper subset）建立双射
    • 打破了"有限集合的真子集一定更小"这条规律
      • ℕ ={1,2,3,4,…} 和偶数 𝐸 ={2,4,6,8,…}
      • 𝐸 是 ℕ 的真子集，因为它把所有奇数都拿掉了
      • 但每个自然数都有一个偶数伙伴，每个偶数也都有一个自然数伙伴，谁都不落单
      • 因此真子集和原集合一样大
      • 这便是无穷集合的定义
