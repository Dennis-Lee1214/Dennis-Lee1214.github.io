Variables and Data Types

Variable

  • Variable变量：类似于盒子，用来存放数据
    • Data Type数据类型：整数，小数，字符
    • Value值：variable中的值
	int num = 3;  // int = Data type ; num = variable name ; 3 = value

Variable type

  • Local 局部变量
    • 在函数内部声明, 只能在函数内部使用
	void function() {
	    int num1 = 3;      // 局部变量
	    printf("%d", num1);
	}

  • Global 全局变量

    • 在所有函数外声明，整个程序都能用

  • Automatic 自动变量

    • 所有局部变量默认就是auto

  • Static 静态变量

    • 函数调用完后，值仍然保留
void function() {
    int local_var = 10;
    static int static_var = 10;
    local_var  += 10;
    static_var += 10;
    printf("Local: %d\n", local_var);
    printf("Static: %d\n", static_var);
}
// main 里调用 3 次
  • 输出：
Local: 20   Static: 20
Local: 20   Static: 30
Local: 20   Static: 40

  • local_var每次调用都重新创建，从10开始, static_var只在第一次初始化

  • External 外部变量

    • 用external声明, 变量能在多个.c文件之间共享

  • Register 寄存器变量

    • 变量放进CPU寄存器，访问更快

  • Constant 常量

    • 使用后值不能再修改

Variable name

  1. 只能包含数字，字母，下划线
  2. 只能以字母或下划线开头，不能以数字开头
  3. 不能有空格
  4. 不能是保留字(for, while, if, const....)
  5. 区分大小写

Data type

  • int 整数

    • 范围: -2147483648～2147483647 约21亿
    • int num_dec = 3.15; 输出3 不是四舍五入，直接丢掉小数
    • \n表示换行

  • float和double 小数

    • 都可以存小数，double精度更高，占内存是float的两倍
    • printf默认6位小数，float num1 = 0.0000003; 用%f会显示0.000000, 用%.7f 才能显示0.0000003. %.xf x显示的小数位数
    • float num2 =3; 也可以，会自动变成3.000000

  • char 字符

    • 只存一个字符，用单引号 ‘a’
      - 注意不是双引号
      - 字符在电脑里是数字'a' = 97 'b'=98

  • bool 布尔

    • 只有true 1和false 0
    • 需要#include <stdbool.h>
    • 打印用%d，所以会显示1或0

  • void 空

    • 表示 “没有值”，不能用来声明变量，如void num1;会报错
    • 只用于函数返回类型、 参数、指针，例如void function1()表示这个函数不返回任何值

Arrays and loops

Arrays

  • struct 结构体: 把不同类型的数据打包
struct module {
    int studentID;
    float score;
};              // 注意：结尾必须有分号！

int main() {
    struct module comp1312;          // 创建一个 module 类型的变量
    comp1312.studentID = 3303359;    // 用 . 访问成员
    comp1312.score = 87;
    printf("Student ID: %d\n", comp1312.studentID);
    printf("Score: %.2f\n", comp1312.score);   // 87.00 保留两位小数
}
  • enum 枚举: 给数字起名字
    • 从0开始递增: monday=0, tuesday=1......
    • 也可以自定义值
enum days { monday, tuesday, wednesday, thursday, friday };
enum days day = monday;
printf("Day is %d\n", day);    // 输出 0
  • printf and scanf 输入和输出
    • 格式符: %d(int), %c(char), %f(float), %lf(double)
    • scanf里必须加&，意思是这个变量的内存地址，将用户的输入写入这个变量
    • printf只是读取值，不需要&
printf("%d", variable_name);    // 输出
scanf("%d", &variable_name);    // 输入
  • Operators 运算符
    • Arithmetic 算数: 加法+, 减法-, 乘法*, 结果只保留整数部分除法/, 取余数%
    • Unary 一元: 加一x++, 减一x--
    • Relational 关系: > < >= <= == != 结果都为1或0（真或假）
    • Logical 逻辑: && 意思为与 (AND), ||意思为或(OR), !意思为非(NOT)
    • 简写: x += y ---- x = x+y 以此类推

Conditional Statements 条件语句

  1. if
    • 判断真假, 为T则执行，为F则跳过
int num1 = 3;
if (num1 > 1) {
    printf("Number is larger than 1\n");
}
printf("Completed");
  1. if-else
    • 二选一执行其中一个
if (num1 > 1) {
    printf("Number is larger than 1\n");
} else {
    printf("Number is lesser than 1\n");
}
  1. if-else-if
    • 从第一个判断开始检查，遇到为T的就执行，后面的全部跳过
if (num1 > 1)        { ... }   // 条件 1
else if (num1 == 1)  { ... }   // 条件 2
else if (num1 == num2) { ... } // 条件 3
else                 { ... }   // 都不满足
  1. Nested if-else 嵌套
    • 多层if-else，先判断最外层的大类，再判断小类
if (num1 > 1) {
    if (num1 == 1) {...} else {...}
} else {
    if (num1 == num2) {...} else {...}
}
  1. switch
    • if- else-if的另一种写法，适合拿一个变量和多个固定值比较
switch (num1) {
    case 1: printf("Case 1\n"); break;
    case 2: printf("Case 2\n"); break;
    case 3: printf("Case 3\n"); break;
    default: printf("Default\n"); break;
}

Loops 循环

  1. for 循环
  • initialize初始化，循环开始前执行一次 ; test 判断，每一轮循环开始前检查，T才执行循环 ; update 更新 ，每一轮循环体结束后执行
for (initialize; test; update)
{
    // 循环体
}
  1. while 循环
  • 与for循环的区别只有三个是拆开写的
int i = 0;              // ① 初始化：写在循环外面
while (i < 5)           // ② 判断
{
    printf("COMP1312\n");
    i++;                // ③ 更新：写在循环体里面
}
  1. do-while循环
  • 判断位于循环后，因此最少执行次数为1次
  • 结尾必须加分号
int i = 5;
do
{
    printf("Countdown: %d\n", i);
    i--;
} while (i > 0);       // 注意：结尾有分号！
  1. Array 数组循环
  • 以下例子为给五个盒子fuzhi
int arr_int[5];

for (int i = 0; i < 5; i++)
{
    arr_int[i] = i;                               // 第 i 个盒子放入 i
    printf("arr_int[%d] : %d\n", i, arr_int[i]);
}
  1. 循环控制语句
  • break；意思为立刻跳出循环，不管条件成不成立
  • continue；跳过本轮循环体剩下的代码，直接开始下一轮
for (int i = 0; i < 5; i++)
{
    printf("Counter: %d\n", i);
    if (i == 2)
    {
        break;               // i 等于 2 时才退出
    }
}

for (int i = 1; i <= 5; i++)
{
    if (i == 3)
        continue;            // i 是 3 时，跳过下面的 printf
    printf("%d\n", i);
}

Pointers 指针

What is pointers

  • 指针是一种数据类型，存的是内存地址
  • 可以是变量、函数或是另一个pointers的地址
  • 可以访问修改地址里的数据
  • 输出地址使用%p
  • 指针自己也是变量，也有地址

Declare a pointer 声明指针

data_type *pointer_name;
	
或
	
int *numint_p;
float *numflt_p;
double *numdb_p;
char *char_p;
  • 含义
    • " * "表示这是一个指针
    • 指针的类型要和它指向的变量类型一致int用 int*

Pointer assignment 指针赋值

int num1 = 1;
int *numint_p = &num1;
  • & 叫address-of operator 取地址运算符，用作获取已有变量的地址

variables in memory 内存中的变量

  • 每个变量都有两个属性
    • value 存放的值
    • address 在内存中的位置
  • 不同类型如何打印值和地址:
类型 值的格式符 地址格式符
int %d %p
double %lf %p
float %f %p
char %c %p
  • 打印地址时一定要用&变量名 + %p
    • printf(“Address num1: %p\n", &num1);
    • %p这一类为format specifier格式说明符，作用是告诉printf要输出的值是什么类型

Accessing with pointers 通过指针访问

int main(){
	
	int num1 = 1;
	int *ptr_num1 = &num1;
	
	printf("Value of num1 is %d\n",num1);
	printf("Value of ptr_num1 is %d\n",*ptr_num1); //*为解引用运算符
	
	printf("num1 address: %p\n", &num1);
	printf("ptr_num1 address: %p\n",ptr_num1);
	
	printf("ptr_num1 address2: %p\n",&ptr_num1); //指针自己的地址
}

Out put:
Value of num1 is 1
Value of ptr_num1 is 1
num1 address: 0061FF18
ptr_num1 address: 0061FF18
ptr_num1 address2: 0054xf3
  • *ptr_num1用%d打印得到1，说明 是dereference operator解引用运算符，顺着地址取值
  • &num1和ptr_num1打印出相同的address因为pointers存的就是num1的address
  • &ptr_num1打印的是指针自己的地址

Modify value 修改值

  • 方法1: num1 = 50; 直接修改变量的值
  • 方法2: * ptr1 = 38; 通过指针修改值
  • Example:
	int num1 = 3;
	int *ptr1 = &num1;
	
	printf("Value num1 before: %d\n", num1);
	printf("Value num1 before: %d\n", *ptr1);
	
	*ptr1 = 38;

Out put:

Distinguish between & and 区分&和*

int num = 10;
int *p = &num;

   &num  ──►  num 的地址
   p     ──►  存着 num 的地址(和 &num 相同)
   *p    ──►  num 的值(10)
   &p    ──►  p 自己的地址

Multiple pointers 多个指针

  1. 两个pointers指向一个num1
int num1 = 3;
int *ptr1 = &num1;
int *ptr2 = &num1;
  • 两个pointers指向一个num1，读出的地址都是一样的，只是他们各自的address不同
  1. Double Pointers 双重指针
int num1 = 1;
int *ptr1 = &num1;
int **ptr2 = &ptr1;
  • ptr2 是 "指向指针的指针",所以类型要多一个 *
  • ptr2 含义是ptr1的地址
  • *ptr2 含义是ptr1的值，即num1的地址
  • **ptr2 含义是num1的值
  1. Chain pointer 链式指针
int *ptr1 = &num1;
int **ptr2 = &ptr1;
int ***ptr3 = &ptr2;
  • 规律一样，***ptr3 = 47; 连剥三层，最终修改num1
  • 有几个 ，解引用就要用几个

Pointers and Arrays 指针与数组

  1. 数组名就是首元素地址
int arr[3] = {10, 20, 30};
int *ptr1;
ptr1 = arr;      // 注意:不需要写 &arr
  • ptr1的值是0061FF10,指向arr[0]
  1. pointers可以像数组一样用下标
  • arr[i] 和 ptr1[i] 完全等价
  • &arr[i] 和 &ptr1[i] 地址相同
  • *ptr1 等价于 ptr1[0]
  1. 指针算数遍历数组
  • ptr1++ 指针移到下一个元素
  • ptr1-- 退回上一个元素
  • ptr1 = ptr1 + 2
  • ptr1++ 不是地址 +1,而是加一个元素的大小。int 数组地址 +4,double 数组 +8
  • 使用for循环配合ptr++遍历整个数组
for (int i = 0; i < 3; i++) {
    printf("Current value: %d\n", *ptr1);
    ptr1++;
}
  1. address的step取决于类型(int double)
  • int数组: 地址 6422284 → 6422288 → 6422292, 间隔 4
  • double数组: 地址 6422272 → 6422280 → 6422288,间隔 8
  1. 用&arr[i]指向任意元素
int *ptr1 = &arr[0];
int *ptr2 = &arr[2];
  • 输出10 和 30

Pass by reference 传引用

  • 函数参数默认是pass by value传值，函数拿到的是一份拷贝，改了也不影响外面
void func1(int *a, int *b);   // 形参是指针
func1(&x, &y);                // 实参传地址
  • 如果写成 void swap(int a, int b)，交换的只是拷贝，x、y不会变
传什么 形参写法 实参写法 函数里怎么改
普通变量 int *a &x *a =...
指针变量 int *w ptr *w = ...
数组 int *ar或int ar[] arr ar[i] = ...
结构体 struct personal *p &p p->age = ...
  1. Swap
void swap(int *a, int *b)
{
    int c = *a;   // 暂存 x 的值
    *a = *b;      // 通过地址修改 x
    *b = c;       // 通过地址修改 y
}

int x = 10;
int y = 40;
printf("x: %d , y: %d\n", x, y);
swap(&x, &y);                  // 传地址
printf("x: %d , y: %d\n", x, y);

/* Output
x: 10 , y: 40
x: 40 , y: 10
*/

int sum(int *a, int *b)

int total;

int y = 60;
printf("x: %d\n", x);

  1. 函数返回指针
int *findMax(int *ar, int size)
{
    int *max = &ar[0];          // 先假设第一个元素最大
    for (int i = 1; i < size; i++)
    {
        if (ar[i] > *max)       // *max 是当前最大值
            max = &ar[i];       // 记住更大元素的地址
    }
    return max;                 // 返回地址（指针）
}

int arr[5] = {12, 45, 7, 30, 18};
int *p;

p = findMax(arr, 5);            // p 指向 arr[1]
printf("Max value: %d\n", *p);
*p = 100;                       // 通过返回的指针直接修改原数组
printf("arr[1]: %d\n", arr[1]);

/* Output
Max value: 45
arr[1]: 100
*/

int *ptr = NULL;   // 暂时不指向任何东西时，先设成 NULL
if (ptr == NULL) ...

Void pointer

  • void *是通用指针，可以存任何类型变量的地址
void *ptr;
ptr = &num;      // 可以指向 int
ptr = &letter;   // 也可以指向 char
  • 限制
    • 不能直接解引用，需要先转换，例如：*(int *)ptr, 先当成 int* 再取值
    • 不能做指针运算
    • 不能 ++ / --
int num = 10;
char letter = 'c';
char *name = "John";

/* 1. void 指针可以指向任何类型 */
void *ptr;

ptr = &num;                               // 指向 int
printf("num: %d\n", *(int *)ptr);         // 先转成 int* 再解引用

ptr = &letter;                            // 改为指向 char
printf("letter: %c\n", *(char *)ptr);     // 先转成 char* 再解引用

/* 2. void 指针数组：一个数组存不同类型的地址 */
void *arr[3];
arr[0] = &num;      // int*
arr[1] = &letter;   // char*
arr[2] = &name;     // name 是 char*，所以 &name 是 char**

printf("arr[0]: %d\n", *(int *)arr[0]);
printf("arr[1]: %c\n", *(char *)arr[1]);
printf("arr[2]: %s\n", *(char **)arr[2]); // 解引用一次得到 char*（字符串）

/* Output
num: 10
letter: c
arr[0]: 10
arr[1]: c
arr[2]: John
*/

void *ptr = &num;

printf("%d\n", *ptr);   // 不能直接解引用：编译器不知道要读几个字节
ptr + 1;                // 不能做指针运算：void 没有大小
ptr++;                  // 不能自增 / 自减

printf("%d\n", *(int *)ptr);   // 解决方法：先强制转换(cast)再使用

Debugging and testing 测试和调试

Memory Management 内存管理

  • C语言没有垃圾回收，借到的内存需要自己还
  • 常见问题：
    1. Dangling pointer 悬空指针——内存已经free了指针还在用
    2. Buffer Overflow 缓冲区溢出——写入的数据超过分配大小
    3. Memory Leak 内存泄漏——分配了但从来没free
    4. Double free 重复释放——对同一个指针free两次
  • 四个函数
    1. malloc() - memory allocation
      • int *ptr = (int*) malloc(3 * sizeof(int));
      • 分配一整块内存，大小单位是字节
      • sizeof(int) 通常是 4，所以 3 × 4 = 12 bytes
      • 内存不初始化，里面是 garbage values垃圾值
    2. calloc() - contiguous allocation
      • int *ptr = (int*) calloc(3, sizeof(int));
      • 两个参数：元素个数 n 和 每个元素大小
      • 内存同样是 12 bytes，但全部初始化为 0
    3. realloc() - re-allocation
      • ptr = realloc(ptr, 5 * sizeof(int));
      • 改变已分配内存的大小
      • 原有数据保留，新增部分是垃圾值
      • realloc 可能把数据搬到一块新地址，所以必须用返回值更新 ptr
    4. free()
      • free(ptr);
      • 释放内存，还给系统
      • 不要对同一个指针调用两次
    5. 写法
#include <stdio.h>
#include <stdlib.h>

int main(void) {
    int *ptr = malloc(3 * sizeof(int));
    if (ptr == NULL) {              // ② 检查是否分配失败
        printf("Allocation failed\n");
        return 1;
    }

    ptr[0] = 30; ptr[1] = 20; ptr[2] = 50;

    free(ptr);                      // ① 每次分配都要配对 free
    ptr = NULL;                     // ③ free 后设为 NULL，防止悬空指针
    return 0;
}

Testing 测试

  • Testing就是评估程序，找出错误
  • 手动测试和自动化测试，各有优缺点
  • Black / White / Grey Box Testing
    1. 黑盒测试
      • 看不到代码，测试视角是用户，关注输入→输出是否正确
      • 优：不需技术、适合大系统、以用户为中心、用例容易复现
      • 缺：测试失败时找不到原因
    2. 白盒测试
      • 看得到全部代码，测试视角是开发者，关注内部代码、结构、逻辑
      • 优：测试彻底，能更早发现bug，更全面
      • 缺：需要技术能力，依赖测试者水平
    3. 灰盒测试
      • 看到部分代码，测试视角两者结合，关注功能和内部结构设计用例
      • 优：兼顾两者，平衡，成本合理
      • 缺：对内部代码访问有限，设计用例更复杂
  • 功能测试与非功能测试
    • Functional——功能是否符合需求
      1. Unit testing: 测单个组件，例如一个函数
      2. Integration testing：测多个组件之间的配合
      3. System testing：测整个系统
    • Non-Functional——速度、安全、可扩展性等做的好不好
      1. Performance：速度、响应时间
      2. Usability：用户体验、好不好用
      3. Compatibility：在不同OS/平台/环境下能否运行
    • Test case 测试用例
      1. Test Case ID：唯一编号
      2. Objective / Description：这个用例要验证什么
      3. Input：输入数据——要特别测：
        • Edge cases（边界值）：最大值、最小值，如 0、负数
        • Unexpected inputs（异常输入）：特殊字符、类型错误、空字符串
      4. Expected Output：预期结果（测试前就要写好）
      5. Actual Output：实际运行结果
